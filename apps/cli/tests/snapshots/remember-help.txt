bilbo remember: keep files or a note as entries, and what changed in them since.

Usage:
  bilbo remember <file|folder> [--kind <kind>] [--tag <tag>]...
                 [--follow]
  bilbo remember - [--tag <tag>]...

Options:
      --kind <kind>  Run this kind, not the one that claims the files
      --tag <tag>    Declare this tag for every entry the run keeps
      --follow       Save the target as a follow in the config file

Kinds:
  markdown  .md files, one record per line
  session   Claude Code and Codex sessions, one record per JSONL line

Output:
  new <n>, appended <n>, new generation <n>, unchanged <n>, refused <n>
  records <n>, raw bytes <n>, stored bytes <n>

Exit:
  0  success
  1  a refused file or note, nothing to keep, a store or index failure
  2  usage or config error, or a config file --follow cannot write

Examples:
  bilbo remember ~/notes --follow
  echo 'The beet seeds are in the drawer.' | bilbo remember - --tag garden

Docs: https://github.com/delucca/bilbo/wiki/Commands#remember
