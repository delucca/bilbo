bilbo recall: search what bilbo keeps and print the best chunks and notes.

Usage:
  bilbo recall <query>... [--in <label>]... [--kind <kind>]...
               [--budget <tokens>] [--page <n>]

Options:
      --in <label>       Search what a label or an id names; repeat it for more
      --kind <kind>      Search entries of this kind only; repeat it for more
      --budget <tokens>  Cap chunks at this many tokens, more if no note matches
      --page <n>         Print that page; a more: line names the next

Output:
  === <ref> <n> lines   a hit's header (tab-separated), then <n> lines of text
  ... note              a note; its first line: its records, then their day
  ... part <k>/<m>      one piece of a record too long for a chunk
  ... cut               the last hit of a list, cut to fit its room
  <ref>                 bilbo read takes it: the end of the id and the records
  more: <command>       the last line when a list goes on: prints the next page
--in takes an id, tag:<name> or words of a label; a leading - takes =: --in=-x

Exit:
  0  at least one hit
  1  nothing matched, no store, no search index, or a store or index failure
  2  usage or config error

Examples:
  bilbo recall --in bilbo --in notes --budget 1500 -- release checklist

Docs: https://github.com/delucca/bilbo/wiki/Commands#recall
