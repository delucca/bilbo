# Tasks

Run every command below from the repo root as `nix develop -c sh -c '<command>'`, with `CARGO_TARGET_DIR` set to the checkout's `target`. A new file under `src/` or `tests/` needs `git add -N` before any Nix command can see it. `add-note-history` and `add-note-scope` are archived: this change uses `host::swap::rename_new`, `shared::hash`, `note::versions::lock`'s locking habit and the `scope.*` keys. Until 5.1 calls them, the identity modules have no caller in the binary, so intermediate gates run clippy as `cargo clippy --locked --all-targets -- -D warnings -A dead_code` (the allowance on the command line only, never in code); 6.1 and 6.2 run it without the allowance.
