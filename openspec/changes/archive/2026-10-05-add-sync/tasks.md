# Tasks

Run every command below from the repo root as `nix develop -c sh -c 'export CARGO_TARGET_DIR="$PWD/target"; <command>'`. A new file under `src/` or `tests/` needs `git add -N` before any Nix command can see it. Changes 1 to 3 are archived: this change extends their code. Until 5.6 wires the engine into `bilbo watch`, the new library code is reached only from unit tests, so clippy runs as `cargo clippy --locked --all-targets -- -D warnings -A dead_code` from 1.4 to 5.5; from 5.6 on it runs with no allowance. Unit-test filters name the module path, such as `note::merge::`.
