# Tasks

Run every `cargo` command below from the repo root as `nix develop -c sh -c '<command>'`, with `CARGO_TARGET_DIR` set to the checkout's `target`. A new file under `src/`, `tests/` or `plugins/` needs `git add -N` before any Nix command can see it. CLI tests run the built binary through `tests/common/` with a clean environment, so every library and cite test sets `BILBO_HOME`, `HOME` and `XDG_STATE_HOME` inside its `TempDir`, and lands its sources through `bilbo library stage` and `land` as `add-library-store`'s tests do. `$PLUGIN_CHECKS` stands for `claude plugin validate . && claude plugin validate plugins/bilbo && PYTHONDONTWRITEBYTECODE=1 python3 ~/.codex/skills/.system/plugin-creator/scripts/validate_plugin.py plugins/bilbo`, run outside the dev shell; expect one missing-version warning from each `claude plugin validate`, and never pass `--strict`. `add-library-store` is archived before this change is applied.
