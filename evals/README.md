# Evals

Experiments that measure how well bilbo and other memory strategies retain and retrieve
information from coding sessions.

| Eval | What it measures |
|---|---|
| [Retrieval](retrieval/README.md) | How much of a question’s answer a strategy retrieves from past sessions within a fixed reading budget. |

Start with the retrieval overview for setup and a small run. Its
[results](retrieval/results/README.md) explain how to read the scores and their limits.
