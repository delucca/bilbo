# Questions

Questions about what a project’s coding sessions settled: decisions, unfinished work,
procedures, and other facts that its files do not answer. Each reference fact cites the
session lines that support it and must hold at the end of the recorded sessions.

The dataset has 167 questions: 143 answerable and 24 with no answer. The current retrieval
eval scores only the answerable ones.

## Files

| File | Contents |
|---|---|
| [questions.jsonl](questions.jsonl) | One question per line, with wording, reference facts, and evidence. |
| [classes.json](classes.json) | Seven classes and their headline weights. |
| [dropped.jsonl](dropped.jsonl) | Rejected candidates and the reasons they failed. |
| [methodology.md](methodology.md) | Full schema, counts, selection rules, mining history, frozen prompts, and corrections. |

## Classes

| Class | Asks for |
|---|---|
| `overview` | What is known about a topic. |
| `status` | Where work stopped and what remains. |
| `decision` | What was chosen and why. |
| `rules` | Project conventions and constraints. |
| `procedure` | Ordered steps and their commands. |
| `fact` | An exact value or setting. |
| `refind` | When or in which session something happened. |

Class weights reflect 317 real memory queries. Each class contributes its weight regardless
of how many questions it contains.

## Read a row

`repo` identifies the project. `wording.original` contains the developer’s `prompt` and the
agent’s `query`. `facts` lists the required answer, with exact `keys` where needed and
`evidence` pointing to session IDs and one-based line ranges. `stale` records superseded
values; `abstain` marks a question with no answer.

Committed questions are frozen. Query variations are generated by
[`vary.sh`](../scripts/vary.sh), with checks that they preserve meaning and project terms.
They test sensitivity to wording and stay separate from the headline score.

See the [schema](methodology.md#a-question),
[exclusion rules](methodology.md#what-a-question-is-not), and
[mining method](methodology.md#how-the-questions-were-made) before changing the dataset.
