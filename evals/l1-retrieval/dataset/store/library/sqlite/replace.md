# Replace

REPLACE 

The REPLACE command is an alias for the "[INSERT OR REPLACE](lang_conflict.html)" variant of the [INSERT](lang_insert.html) command. This alias is provided for compatibility other SQL database engines. See the [INSERT](lang_insert.html) command documentation for additional information.
